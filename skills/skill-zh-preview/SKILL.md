# 中文技能目录预览

- 用户要求打开目录时，调用本插件的 `open_skill_catalog` 工具，展示返回的目录面板。
- 若客户端只显示统计文本或用户说面板未打开，在当前工作区使用 `python3 -B <插件根目录>/scripts/codex_preview.py --html <新文件>` 导出离线目录。插件根目录是从本文件向上两级的目录。选择一个尚不存在的输出文件，优先使用聊天已有的输出目录，并给用户可点击的文件链接。
- 预览使用本机的已有汉化索引和能扫描的技能说明。用户需要新增汉化时，转用独立安装的 `skill-zh` 技能。
